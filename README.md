# Quadlabs

A modern, animated landing site for **Quadlabs** — a freelance digital studio. Built with Vite, React, TypeScript, Tailwind CSS v4 and Framer Motion.

## Features

- Sticky blur navbar with mobile menu
- Animated hero with staggered reveals and ambient glows
- Trusted-by marquee
- Services grid, animated stat counters
- Selected work showcase
- Transparent 4-step process
- Testimonials
- Contact form with budget selector (client-side success state)
- Fully responsive, dark premium theme

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (default http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
